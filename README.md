# tadpole_cornification
The molecular basis of hard cornification in the keratinized jaw sheaths and keratodonts of anuran tadpoles

This repository contains scripts and associated data files for our manuscript on the The molecular basis of hard cornification in the keratinized mouthparts of anuran tadpoles. If you have any comments or questions, please email me at daniel.j.paluh@gmail.com

File contents

HMM_analysis.zip - data and python scripts for HMM searches; R script for visualizing the spatial organization of keratin genes in Bombina bombina.

phylogenetic_analyses.zip - fasta files, alignment files, IQtree tree files, and R script for visualizing phylogenies.
