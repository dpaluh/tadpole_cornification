## Readme for RNAseq analyses

- `Bombina_RNAseq.R` filters differentially expressed genes among three developmental time points in Bombina orientalis [A (before oral disk formation; stomodeum), B (during oral disk formation), and C (corinfied mouthparts)]
- `STAR_ReadsPerGene.zip` contains STAR reads per gene counts for 9 samples (3 replicates per time point)
- `6Cluster.RData` contains MFuzz cluster results for gene ontology and functional group enrichment analysis
